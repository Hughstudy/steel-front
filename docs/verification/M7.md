# M7 — AI observer and renewable supplies

Verified 2026-10-11. Scope: the two requested features as one milestone, with no new npm dependencies or server runtime.

## Behavior

- New Skirmish → Watch AI vs AI initializes two normal planners at the selected difficulty. The selected faction is AI 1; AI 2 uses the other faction. Full observer visibility is presentation-only: simulation fog remains enabled for both players.
- Camera/minimap controls, base-focus buttons and click inspection work. Gameplay commands pass through a shared observer guard; production and army controls are hidden. Results identify the winner without assigning a human victory/defeat. Watch Again preserves the setup.
- Both skirmish modes include two neutral Infinite Supply Yards per map, one near each base. Map positions, building stats and the infinite capability are data-defined. Each yard is within 12 route-cost tiles of its own starting position. Ten finite supply dumps per map remain unchanged.
- Infinite yards retain bounded, JSON-safe stock. Normal truck rates, cargo capacity, dock contention and HQ deposits still apply. Finite dumps still exhaust and trucks retarget.
- The optional match mode round-trips in version-1 saves; an absent mode defaults to normal play. Actual saves from older game-data revisions remain rejected under the existing rules-hash contract.

Simulation stepping was temporarily frozen for this input check so AI commands could not confound the command counter.

The results table labeled both columns AI and Watch Again restarted in observer mode. This was an accelerated simulation, not a 42-minute real-time performance run.
