# M6 — Complete match and static delivery: verification

**Date:** 2026-10-10 · **Base commit:** `269b380` (M0–M5 review)

## Scope and changed systems

- **Match flow (UI):**
  - Main menu: New skirmish, Continue, Load, Settings, Controls, and a development-scenario launcher.
  - Skirmish setup: faction, map and AI difficulty cards, built from data.
  - Pause menu (P / F10 / top-bar button, or automatically when the tab is hidden): Resume, Save, Load, Settings, Controls, Quit to menu.
  - Results screen: Victory / Defeat / Stalemate with a per-side statistics table, plus View battlefield, Main menu and Play again.
  - All menus are native `<dialog>`s managed by one `DialogStack` (`src/ui/menus.ts`). Esc goes back one level, and gameplay input is ignored while a dialog is open.
  - The scenario and difficulty selectors were removed from the top bar. The top bar now shows a match clock, an audio toggle (M) and a pause button.
- **Objective rule** (`World.updateObjectives`, scenario flag `victory`):
  - Before deploying, a player is kept alive by its deployable unit (MCV). After it owns an objective building, only the HQ counts.
  - Losing your last objective is a defeat. If both sides lose theirs on the same tick, the match is a draw.
  - `world.outcome` freezes `step()`.
  - Sandbox scenarios (`victory` false) never end.
  - Per-player statistics: units/buildings built and lost.
- **Skirmish data:**
  - `data/skirmish.json`: credits, offered maps, default map and faction, and each faction's starting units.
  - `src/sim/skirmish.ts` builds a validated scenario from `MatchSetup {map, faction, difficulty}`.
- **Second map:**
  - `data/maps.json` gains the generation parameters (`generation`) and palette overrides (`palette`). Defaults equal the Lowlands, which generates unchanged.
  - New preset **The Ardennes**: denser forest, a southern river, northern rocks, different roads, farms, spawns and resources, and a winter palette.
  - `tests/helpers.ts validateSkirmishMap` checks that both maps meet these rules:
    - a deploy site within 4 tiles of each spawn;
    - at least 220 buildable tiles within radius 10;
    - at least 2 supply dumps within 30 path tiles;
    - every resource reachable;
    - the two bases connected by ground.
- **Versioned saves** (`src/sim/save.ts`):
  - JSON `{format: "steel-front-save", version: 1, rules: FNV-1a hash of all data files, map checksum, setup, world}`.
  - The world snapshot covers:
    - entities, players (queues, AI state, fog masks run-length encoded, remembered structures in Map order);
    - pending placements and commands;
    - the random state and counters;
    - the projectile pool, including its free list;
    - navigation occupancy, structure arrays and revision.
  - Caches (distance fields, spatial grid, pathfinder scratch) are rebuilt.
  - Loading parses and validates everything (shape templates, type IDs, ranges, cross-references, mask sizes, projectile pool) into a **fresh** World. The running match is never touched by a rejected file.
  - Readable reasons are given for: invalid JSON, not a save, unsupported version, different game data, map mismatch, unknown setup, and bad fields.
  - Size limit: 3,000,000 characters.
  - Three localStorage slots; storage-full errors are reported.
- **Audio** (`src/audio/sfx.ts`):
  - Every effect is synthesized with WebAudio (oscillators plus seeded noise bursts); there are no audio files.
  - The AudioContext is created or resumed inside the first pointer or key gesture (checked against MDN via context7).
  - Up to 14 voices, with a minimum spacing between repeats of each cue.
  - Sound fades with distance from the view, and only visible events are heard. Audio is held while the tab is hidden.
  - Volume, mute and screen-shake preferences are kept in localStorage.
- **Presentation:**
  - Screenshake from nearby heavy explosions and deaths. It is disabled under `prefers-reduced-motion` and can be switched off in Settings.
  - A slow day-light tint from the map palette (20-minute cycle).
  - Effects, markers, selection and terrain renderer are cleared or disposed on every match change.
- **AI tuning (`data/ai.json`, `ai.ts`):**
  - New `minCredits` gate on base-plan steps.
  - Veteran and Regular were retuned so that higher difficulty is stronger (see below).

## AI difficulty tuning

**Before the retune**, Veteran AI vs Recruit or Regular AI (both factions, both maps, both spawns, 12 games): the stronger level won **1 of 12**. Several choices weakened the Veteran AI:

- 70% tempo spent credits on redundant production buildings.
- 4 trucks blocked the vehicle queue, so the army was infantry-only.
- 3 engineers.
- A power margin.
- Large wave thresholds.

**After the retune** (same 12 pairings), the stronger level won **6**, lost **4** and drew **2**. The changes:

- `minCredits` 2500 on the second barracks and factory;
- Veteran tempo 100%;
- 2 trucks and 2 engineers;
- power margin 0;
- waves of 5 + 3n, at most 24;
- first wave 6000, then every 2400 ticks.

Pressure against a passive player (Lowlands first-wave arrival): Veteran tick 6001 < Regular 7201 < Recruit 9001.

## Known limitations

- AI-vs-AI difficulty is only partly ordered.
- Mirror matches show a west-spawn advantage on both maps.
- On the Ardennes, the Veteran first wave (tick 9111) is no earlier than the Recruit one (9001), because of the longer forest route.
- Winter trees use the generic tree sprites; only the ground palette changes.
- The victory QA used the AI planner to drive the player's side. No fully hand-played 20-minute match was completed.
- Sound output was verified by voice counts and context state, not by ear.
- The production panel keeps its last match's DOM behind the main menu until a new match starts. It is covered by the modal, so it cannot be clicked.
- Sustained frame pacing was observed, not measured over a long session, on a separately defined midrange laptop.
- Caddy is not installed in this workspace. The README Caddy examples (domain root and `handle_path` subdirectory) were not run here. The same subdirectory layout was verified with a plain static file server.
