# Asset sources

All terrain, trees, unit sprites (vehicles, infantry, insignia), order markers, stones, roads, bridges, fields, cottages, ruins, minimap art, icons, and HUD decoration are drawn procedurally by this project's Canvas 2D, CSS, or inline SVG code. No external images, fonts, audio, copied code, or game assets are included.

System fonts are rendered from the player's device. Reference projects listed in PROJECT.md inform behavior/architecture only; none of their code or assets is used.

`docs/m0-preview.jpg` is a screenshot of the project's own M0 production build, captured during local browser verification.

`docs/m1-maneuvers.jpg` is a screenshot of the project's own M1 development build.
