# Steel Front Claude Code handoff

Read these files before working:

1. AGENTS.md — repository working agreements.
2. PROJECT.md — the user's mission, constraints and milestones.
3. STATUS.md — current completion state and verification evidence.
4. CLAUDE_PLAN.md — full implementation plan, design defaults and acceptance checks.

M0 is complete. The next implementation session is M1 unless STATUS.md or the user's latest instruction says otherwise. Implement one milestone per session, preserve existing work, and stop after a verified, committed checkpoint. The full plan does not authorize implementing all remaining milestones in one session.

Print the current milestone's file plan before editing. Explain any new dependency before adding it. Finish implementation with passing tests/build, actual browser/manual testing, updated STATUS.md and docs/verification evidence, and a Git commit. Do not claim unperformed checks passed. Follow the user's latest instruction if it changes this workflow.
